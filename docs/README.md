## 文档约定

- 新增文档统一放在本目录，并在本索引对应分类中登记一行
- 同目录文档间相互引用直接写文件名（如 `[部署文档](CS架构部署文档.md)`）；引用根目录文件用 `../`（如 `[../README.md](../README.md)`）
- 发布类文档涉及的服务器地址、账号密码等敏感信息以工作区记忆/技能中的固定环境表为准，文档中不写明密码
