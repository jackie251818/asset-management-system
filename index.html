飞书多维表格同步

本机模式不支持飞书同步,请先连接 C/S 服务器。
小白引导 - 3 分钟搞定飞书同步 (点击收起)
在飞书开放平台创建应用并获取凭证
① 打开 open.feishu.cn/app，点「创建企业自建应用」
② 应用名称随便起，比如「固定资产同步机器人」
③ 左侧「权限管理」→ 搜索 多维表格 → 勾选全部多维表格相关权限 → 批量开通
④ 左侧「版本管理与发布」→ 创建版本 → 申请线上发布（管理员审批后生效）
⑤ 回到「凭证与基础信息」，复制 App ID 和 App Secret（下面第 1 步要用）
创建/打开要同步的多维表格
① 在飞书里打开或新建一个多维表格（不是普通文档）
② 点右上角「···」→「更多」→「添加文档应用」→ 搜到刚创建的应用 → 添加
③ 点右上角分享按钮 →「复制链接」，拿到类似 https://xxx.feishu.cn/base/bascnxxxxxxxx?table=tblxxx 的链接
把链接粘贴到下面「从飞书链接自动提取」框里，点解析
系统会自动填好 App Token 和 Table ID，你只需手动填入第 1 步拿到的 App ID / App Secret 即可。
